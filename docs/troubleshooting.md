# 故障排查

## Wails 命令找不到 / 构建失败

将 `$(go env GOPATH)/bin` 加入 PATH，使用 README 指定的 Wails 版本。Node 使用 24，执行 `npm ci --prefix frontend`，不要用全局 TypeScript 或忽略锁文件。需要 Apple 的编译工具；仅前端预览不需要构建 macOS 应用。

Go 的模块下载和 npm 安装需要访问对应注册表。先检查网络及代理设置，不要把访问令牌写进提交的 `.npmrc`。

## 显示“未连接”或没有活动节点

确认 Clash Verge Rev 已运行且加载有效配置。Hermit 从当前内核运行状态读取节点；策略组和 DIRECT / REJECT 不属于可绑定的原子节点。在活动节点页点击刷新。

不要把浏览器的示例列表当成真实状态。只有 `npm run dev` 的浏览器预览使用 mock；本地安装版调用真实服务。

## 端口不可用 / 待应用 / 测试按钮不可点击

- 确认总开关和单条映射都已开启。
- “待应用”可点击“应用更改”；配置冲突或恢复提示要先处理。
- 端口需在 1024–65535 之间，不能和其他映射或本机程序冲突。
- 映射有修改或运行状态异常时，旧的测试记录不能代表当前连接状态。

## 可访问网络，但显示“出口节点不符”

这表示请求可达，但捕获的链路没有证实指定节点。查看期望节点和实际链路，检查是否发生节点选择或配置变化。不要仅凭出口 IP 把它当成测试成功。“节点待确认”表示未捕获足够的链路证据。

## 配置冲突或需要恢复

先保留当前数据目录和钥匙串，关闭其他可能修改同一配置的操作，按界面恢复提示处理。不要手工覆盖原脚本或删除事务文件来清除提示；那会丢失恢复依据。无法恢复时，提供脱敏错误信息和版本，不上传完整配置或密文文件。

## 升级、备份和停止使用

1. 正常关闭 Hermit 的映射总开关，确认原脚本已恢复。
2. 退出应用后备份应用数据，并确保 macOS 钥匙串可恢复。只复制加密文件而丢失密钥无法恢复凭据。
3. 替换 `.app` 不会主动删除应用数据；先保留旧版以便需要时回退。
4. 停止使用时，先关闭映射再移除应用。暂时保留数据与钥匙串，确认不再需要恢复后自行清理。

未签名 / 未公证警告不是让你关闭 Gatekeeper 的理由。优先自行从已检查的源码构建，或等待维护者提供可验证的正式发行版。
